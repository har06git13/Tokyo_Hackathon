# タスク: WorldChoices レイアウト崩れ修正

## ステータス: 実装完了（レビュー待ち）

## 背景

スクリーンショットで2つのレイアウト崩れを確認。

1. **ドーナツグラフが1列縦並び**: `DonutChart` が `width="50%"` を持つが、
   親の `Flex` に `gap="1.5vh"` があるため合計幅が 100%+gap を超え、
   1アイテムずつ折り返してしまう。
2. **円グラフのラベル重複**: スライス内にエリア名テキストを描画しているが、
   複数エリアが近接すると重なって判読不能になる。
   凡例（下部 wrap 行）があるため in-slice ラベルは不要。

仕様書 §4.7.2.1・§4.7.2.2 に従い修正する。

## 変更内容

### `client/src/components/game-page/WorldChoices.jsx`

1. `PieChart`: スライス内 `<text>` 要素を削除（`showLabel` ロジックごと除去）
2. `DonutChart`:
   - `width="50%"` → `flex="0 0 calc(50% - 0.75vh)"` に変更（gap 1.5vh の半分を引く）
3. ドーナツ wrap コンテナ: 変更なし（`flexWrap="wrap"` + `gap="1.5vh"` を維持）

## 受け入れ条件

- 円グラフにテキストラベルが表示されない
- ドーナツグラフが2列2行（2×2）で表示される
- スライス色はエリア凡例で識別できる
