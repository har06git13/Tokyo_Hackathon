# task-0310-09: 防災アドバイス免責事項表示

## 概要
「防災に向けてのヒント」セクションにアドバイス下部の免責事項テキストを追加する。

## 関連仕様
- 仕様書 §4.8.7

## 変更ファイル
| ファイル | 種別 | 内容 |
|----------|------|------|
| `client/src/pages/ResultPage.jsx` | 修正 | アドバイス表示の直下に免責テキストを追加 |

## 実装仕様

アドバイスが1件以上表示されている場合（`adviceState.text` が truthy）、その直下に：

```jsx
<Text className="text-subtext" color="var(--color-base13)">
  {adviceState.isLLM
    ? "※このアドバイスは防災資料をもとにAIが生成したものです。実際の避難行動は自治体・公的機関の指示に従ってください。"
    : "※実際の避難行動は自治体・公的機関の指示に従ってください。"}
</Text>
```

## 完了条件
- [ ] LLM 生成時に「AI生成」旨を含む免責が表示される
- [ ] フォールバック時に公的機関指示の免責が表示される
- [ ] 「生存のヒントがありません」表示時は免責を表示しない
- [ ] ローディング中は免責を表示しない
- [ ] スタイルが小文字グレーになっている
