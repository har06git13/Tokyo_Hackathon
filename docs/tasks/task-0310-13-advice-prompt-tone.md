# task-0310-13: LLM アドバイス プロンプト口調調整

## 概要
`adviceService.js` のシステムプロンプトを「〜行動できた。〜しよう！」形式に変更し、
過去行動の事実確認＋前向きな命令形アドバイスの口調に統一する。

## 関連仕様
- 仕様書 §4.8.2（システムプロンプト）

## 変更前の口調
`〜しましょう／〜しておきましょう／〜を心がけましょう`
→ 柔らかい勧誘形。過去行動の評価禁止。

## 変更後の口調
`〜行動できた。〜しよう／〜確認しよう！`
→ 過去行動を事実として肯定的に述べ、今後の備えを「〜しよう」「〜確認しよう」「〜準備しよう」などの命令形・促し形で締める。

## 変更ファイル
| ファイル | 種別 | 内容 |
|----------|------|------|
| `server/adviceService.js` | 修正 | `ADVICE_SYSTEM_PROMPT` 口調指示を変更 |
| `server/advice_cache.json` | 修正 | 旧口調でキャッシュされた既存エントリをクリア |
| `docs/result-page-spec.md` | 修正 | §4.8.2 システムプロンプト説明を更新 |

## 完了条件

- [x] 旧口調の「〜しましょう」指示が削除されている
