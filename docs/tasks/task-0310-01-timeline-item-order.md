# タスク: タイムラインアイテムの表示順序を修正

## ステータス: ✅ 完了

## 概要

`ResultTimelineItem` の表示順序が意図と異なる。
時刻の直後に地点を表示し、その後にアクション名・意義テキストを続ける順に変更する。

## 現状

```
時刻（14:00）
アクション名（帰宅困難者受け入れ施設へ移動）← 赤太字
地点：ウィズ原宿
施設が満員になる寸前に滑り込み、夜の安全を確保。
```

## 要求

```
時刻（14:00）
地点：ウィズ原宿
アクション名（帰宅困難者受け入れ施設へ移動）← 赤太字
施設が満員になる寸前に滑り込み、夜の安全を確保。
```

## 変更ファイル

| ファイル | 変更内容 |
|---------|---------|
| `client/src/components/game-page/ResultTimelineItem.jsx` | JSX 内の要素順を入れ替え |

## 実装内容

`ResultTimelineItem.jsx` の JSX ブロックを以下の順に並べ替える:

1. `{/* 時刻 */}`
2. `{/* 地点 */}` （`!isSns` 条件付き）
3. `{/* アクション名 */}` （赤太字）
4. `{/* 意義テキスト */}`

コードの変更はブロックの順序入れ替えのみ。ロジック・スタイル変更なし。

## 検証

- タイムライン画面で「時刻 → 地点 → アクション名 → 意義テキスト」の順で表示される
- SNSイベント（`isSns=true`）は地点行が非表示のまま維持されている
- ボーダー・スペーシングに変化なし
