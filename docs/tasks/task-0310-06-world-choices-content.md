# タスク: WorldChoices コンテンツ改善

## ステータス: 実装完了（レビュー待ち）

## 変更内容

### 1. 「不明」→「その他」変換（クライアント側）
- API は `"不明"` を返すが、表示時に `"その他"` へ変換する

### 2. エリア表示順の固定
- 渋谷駅周辺 → 道玄坂エリア → 代々木エリア → 青山エリア → その他
- 円グラフ・凡例ともこの順番に従う

### 3. 円グラフ: スライス内に % 数値のみ表示
- エリア名は不要（凡例で識別）
- rate >= 8 のスライスのみ中央に数値を描画

### 4. ドーナツラベル改善
- "同一の最終到達地点" → "同じ避難先だった"（+ 施設名は改行で継続）
- "モバイルバッテリーをレンタルした" → "充電スポットに立ち寄った"
- "現金を下ろした" → "現金を確保した"
- "人と一度も話さなかった" (noSnsRate) → "SNSで情報を集めた" (100 - noSnsRate)

## 受け入れ条件

- 円グラフに数値（%）が表示される
- エリア順が仕様通り
- "不明" が画面に表示されない
- SNS ドーナツが反転値で表示される
